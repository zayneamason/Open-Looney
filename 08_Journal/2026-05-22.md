- **Anything unexpected.** Three small things.
  - **`anchored_at` ORDER BY in load_extraction.** The composer needs the
    "most recent" anchor_method when an extraction has multiple
    extraction_sources rows. SQLite's `NULLS LAST` ordering is non-standard
    but supported, so the query reads
    `ORDER BY es.anchored_at DESC NULLS LAST LIMIT 1`. Tested on the
    Meditations v0.3 cartridge (where auto anchors have NULL anchored_at);
    works. Worth verifying if we ever target a non-SQLite store.
  - **Contestation=1.0 vs None for the no-ledger-events case.** SPEC-004
    §4.3 reference algorithm returns the formula's raw value (1.0 when no
    disputes/filters/reconciliations target the ULID), not None. None is
    reserved for "no ledger present at all." The Meditations v0.3
    cartridge has a ledger (just 2 system genesis rows) so anchored claims
    correctly compose to Contestation=1.0, Resonance=0.0. Tested.
  - **Reader Cargo.toml now pulls chrono.** Modest dependency growth.
    Build time increased ~20s on the first compile (clean target);
    incremental builds unchanged. `default-features=false` keeps the dep
